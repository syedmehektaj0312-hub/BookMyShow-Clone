# 🎬 BookMyShow Clone – Movie Ticket Booking System

A full-stack movie ticket booking web application developed using HTML, CSS, JavaScript, PHP and MySQL.

## 📌 Project Overview

The BookMyShow Clone allows users to explore movies, view available shows, select seats and complete a simulated ticket booking process.

It also includes an admin dashboard to monitor movies, theatres, shows and customer bookings.

## 🚀 Features

### User Module
- Browse available movies
- View movie posters
- Select theatres and showtimes
- Interactive seat selection
- Check seat availability
- Customer details and checkout
- Simulated payment selection
- Booking confirmation
- Printable tickets

### Admin Module
- Secure admin login
- Admin dashboard
- Movie statistics
- Theatre statistics
- Show statistics
- Booking statistics
- Recent booking information

## ⚙️ Installation

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into `htdocs`.
4. Open phpMyAdmin.
5. Create a database named `bookmyshow`.
6. Import the provided SQL database file.
7. Configure the database connection in the backend.
8. Open the project:

http://localhost/bookmyshow/frontend/

## 🗄️ Database Tables

- movies
- theatres
- shows
- bookings
- booking_seats
- admins

## 💳 Payment Information

This project uses simulated payment functionality.
No real financial transactions are processed.
